# MG1
## Devlog
Amy Bi she/her

My MG1 implementation uses the Player class to handle movement and spawn the Basic_Plants_8 prefab via the PlantSeed method. I linked the Player to the Canvas so the PlantCountUI class can dynamically update the seed counts. I pivoted my plan to separate static text from dynamic numbers to fix layout overlapping and improve clarity. I also adjusted the Order in Layer on the plant's Sprite Renderer so seeds appear in front of the player. Finally, I added Time.deltaTime to the movement logic to ensure consistent speed across different frame rates.
